# 2D Space Ship Shooter Proposal

## Repository
https://github.com/LePedroPewpew/2D-Space-Ship-Shooter-Proposal

## Description
This is going to be a game where you have to shoot at asteroids for points in an endless shooter. This is relevant to media since it is a simple game, and is inspired by Shooty Skies, by Mighty Games and Hipster Whale.

## Features
- Feature 1
	- Powerups: This should use a combination of bool and if statements that will determine which powerups using random
- Feature 2
	- Point System: Each asteroid destroyed will award one point and there will be a variable to track said points
- Feature N 
	- Boss: After a certain amount of time, by tracking the age of the player char., a boss will spawn to stop the player's run. 

## Challenges
- How to make an animation run within a pygame window
- How to better optimize object creation.
- How to make UI interfaces within a pygame window.

## Outcomes
Ideal Outcome:
